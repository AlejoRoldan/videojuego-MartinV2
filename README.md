# GOL LAB · versión_astra

Videojuego de tiros libres para practicar multiplicación y división.

[Jugar](https://gol-lab-martin.alejor.chatgpt.site) · [Documentación Astra](astra/README.md) · [Verificación y pendientes](astra/docs/QA.md)

Astra 2.0 implementa controles móviles, física coherente, escenarios variados, pistas, práctica por operación y copa local de 2–4 jugadores. Acceso para amigos pendiente de elegir y verificar.

Código modular sin dependencias en `astra/`. Ejecutar desde esa carpeta: `node tools/dev-server.mjs`. Pruebas: `node --test tests/*.test.mjs` y `node tools/check.mjs`.

La aplicación React preexistente sigue en la raíz; su documentación original se conserva en [README.previous.md](README.previous.md).
